LutaPDF portable mode

While this file sits next to lutapdf.exe, LutaPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the LutaPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move LutaPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\LutaPDF and
%LOCALAPPDATA%\LutaPDF) instead. If LutaPDFData can't be written (for example on a read-only
drive), LutaPDF says so and uses the per-user folders instead.
